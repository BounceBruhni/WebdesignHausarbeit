2. CSS Grid-Layout

Das CSS Grid-Layout ist ein leistungsfähiges Layout-Modul, mit dem sich zweidimensionale Layouts einfach und flexibel umsetzen lassen. Im Gegensatz zu Flexbox, das sich auf eine Achse konzentriert, ermöglicht Grid die Anordnung von Elementen in Zeilen und Spalten. Ein Grid-Container wird mit display: grid aktiviert und kann mit Eigenschaften wie grid-template-columns, grid-template-rows und gap individuell gestaltet werden.

1. grid-template-columns

Definiert die Spaltenstruktur des Grids.

grid-template-columns: 1fr 1fr 1fr;
