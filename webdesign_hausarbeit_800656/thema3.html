3. Text-Styling mit CSS

Mit CSS lassen sich Texte auf vielfältige Weise gestalten. Dazu gehören Schriftart, -größe, -farbe, Auszeichnungen wie fett oder kursiv, Abstände und vieles mehr. Im Folgenden werden fünf wichtige Eigenschaften für das Text-Styling vorgestellt – jeweils mit Beispiel.

1. font-weight

Steuert die Dicke der Schrift, z.B. font-weight: bold;

Dieser Text ist fett.

2. font-style

Setzt den Text kursiv, z.B. font-style: italic;

Dieser Text ist kursiv.

3. text-decoration

Fügt dem Text z.B. eine Unterstreichung hinzu, z.B. text-decoration: underline;

Dieser Text ist unterstrichen.

4. color

Legt die Textfarbe fest, z.B. color: #1976d2;

Dieser Text ist blau.

5. letter-spacing

Bestimmt den Abstand zwischen den Buchstaben, z.B. letter-spacing: 4px;

Mehr Abstand zwischen den Buchstaben
